# 🍔 Sizzle Street

A modern Food Brand Catalog Website I actually developed for my brother. Sizzle Street showcases different food brands and menu offerings through an attractive and user-friendly web interface.

## 🌟 Overview

Sizzle Street is designed to provide users with an engaging platform to explore food brands, featured items, and restaurant information. The website focuses on clean design, simple navigation, and an appealing visual presentation.

## 🚀 Features

- Attractive homepage design
- Food brand catalog display
- Responsive layout
- Easy navigation
- Brand logo integration
- Modern user interface
- Fast-loading static website

## 🛠️ Technologies Used

- HTML5
- CSS3
- Git
- GitHub
